# dsh-memory v1.1 P0：确认流内联化 — 实施规格（定稿版）

> 状态：**定稿**。已吸收第三方评审修订（2026-08-18 二审："通过，需带修订开发"）。
> 本规格可直接交 DevRep 开发。

## 1. 背景与目标

### 1.1 现状缺陷

- 候选累积到「下次会话统一确认」→ 跳过 → 暂存区积灰（评审确认的最核心产品风险）
- 无「忽略」通道；无未确认处理机制

### 1.2 目标

1. 确认发生在**上下文仍热的回合内**（任务刚结束），而非下次会话
2. 候选**极少且确定性曝光**（top 3），类别优先（decision/troubleshooting > pattern）
3. **确认 / 忽略**两分支；忽略可追溯（archive 带 `[ignored]` 标记 + reasonCode）
4. **未确认降级**基于**提醒暴露次数**（非 turn 次数），连续 3 次未处理自动降级为仅日志
5. 全部操作**可逆**（回收站纪律），零新文件

### 1.3 非目标

- 不做 turn-end 自动抽取入库；不做 UI 面板；不改 L2/L3；不做批量 backlog 仪式

## 2. 设计

### 2.1 turn-end 提醒（三态 + 冷却）

**状态 A：暂存区有候选进入曝光窗口（第 M 次提醒）**
```
「有 N 条候选待确认（第 M 次提醒，连续 3 次未处理将自动降级为仅日志）。
 请逐条内联确认：memory_confirm（index=...）归档，或 action=ignore（index=...）忽略。
 曝光窗口外的积压候选（X 条）不参与降级计数。」
```

**状态 B：暂存区为空 / 无曝光候选 → 提醒①（受冷却约束）**
- 触发条件（**全部满足**才提示）：
  1. `inlineConfirm=true`
  2. 本回合**有工具调用**（非平凡回合粗门槛）
  3. 冷却未命中：最近 **5 个 turn** 内未发过提醒①（或每会话最多 1 次，取先到者）
- 文本：
```
「本回合若产生高价值经验（架构决策 / 排障经验优先，≤3 条），请用 memory_state
 写入经验暂存区（格式 - [ ] category: title — body），并立即用 memory_confirm
 内联确认归档。pattern 次优先；user 类偏好请写用户级记忆（scope=user）。」
```

**状态 C：有候选且暴露次数 ≥ confirmStrikes（默认 3）**
- 不出现提醒文本；插件在 turn-end 自动执行降级归档（见 2.3）

- 提醒沿用现有 inbox 防重复队列（同一 pending batch 只一条，source.kind='dsh-memory'）

### 2.2 memory_confirm：确认 / 忽略分支

```yaml
参数:
  index: string        # 1-based 编号或 "all"
  action: enum         # 默认 "confirm"
    - confirm          # 归档进知识库（现有行为）
    - ignore           # 从暂存移除，移入 archive.md 带 [ignored] 标记
  reasonCode: enum     # 可选，默认 "unconfirmed"；用于统计与审计
    - unconfirmed      # 默认：未说明原因
    - duplicate        # 重复
    - wrong-scope      # 归属错误（应写别处）
    - low-value        # 价值不足
    - not-stable-yet   # 尚未稳定
    - incorrect        # 内容有误
  reason: string       # 可选自由文本补充（非强制，降低摩擦）
```

- archive 标记：`## [ignored] 标题 (date) — yyyy-mm-dd 忽略：[reasonCode] [reason]（原分类 xxx）`
- 输出：「已忽略 N 条候选（移入 archive.md，可手动恢复）」

### 2.3 未确认降级：暴露次数语义（修订核心）

**计数单位 = 提醒暴露次数**（不是 turn 次数）：

- 只有**进入曝光窗口**（top 3，见 2.4）的候选才参与计数
- 候选出现在「状态 A 提醒」中，且本轮没有任何 `memory_confirm` 对它生效 → 暴露 +1
- 每个 turn-end 每候选最多 +1（即使同回合多次提醒）
- **overflow 候选（窗口外）不计数**，直到进入窗口
- 计数存储：暂存条目行尾 `[⏳N]`（N=暴露次数，1 起步）；`parseStagedEntries`
  解析时剥离并暴露 `strikes` 字段
- 触发降级：N ≥ `confirmStrikes`（默认 3）→ turn-end 自动移入 archive
  （标记 `[ignored-3x]`）并清出暂存，提醒静默
- 降级为插件侧自动动作（不依赖 agent），全程 `serializedWrite` 串行化

**设计取舍**：行内标记 vs 独立文件 → 行内（零新文件、git 可见、与 state.md 同步演进）；
标记格式固定单一，渲染层一律转成「第 M 次提醒」不直接展示 `[⏳N]`。

### 2.4 候选约束：确定性曝光窗口（修订核心）

- `memory_state` **不硬限制写入条数**（保留 agent 判断空间）
- 但「待确认曝光窗口」**确定性只展示 top 3**，排序：
  1. decision / troubleshooting（并列，按写入时间）
  2. pattern
  3. 其他
- 窗口外候选标记为 **overflow/backlog**（「另有 X 条积压」），**不参与 strike 计数**，
  不展示「第 M 次提醒」，直到进入窗口（前面的确认/忽略后自动补位）
- 渲染：`memory_confirm` 列表 = top 3（带编号）+ 积压计数行

### 2.5 交互流程全景

```
回合结束（turn-end）
  │
  ├─ 有曝光候选（N<3 次暴露）→ 提醒②：M 次提醒，逐条确认/忽略
  │     ├─ confirm → 归档进知识库，清出暂存（窗口补位）
  │     ├─ ignore（reasonCode）→ archive [ignored]，清出暂存
  │     └─ 未处理 → 该候选暴露 +1
  │
  ├─ 无曝光候选 → 提醒①（有工具调用 + 冷却内）：提炼 ≤3 条，写入即确认
  │
  └─ 有候选暴露 ≥3 → 插件自动降级归档 [ignored-3x]，静默
```

### 2.6 配置项（新增）

```yaml
- id: dsh-memory
  config:
    inlineConfirm: true      # 总开关：false = 恢复旧版提醒（不内联、不降级）
    confirmStrikes: 3        # 未确认暴露次数上限（默认 3）
    remindCooldownTurns: 5   # 提醒①冷却：最近 N 个 turn 内不重复（默认 5）
```

## 4. 测试计划（tests/confirm-flow.spec.ts）

1. **提醒三态**：空（冷却内不发 / 冷却外 + 有工具调用发）/ 有曝光候选 / 达降级线静默
2. **暴露计数**：仅「出现在提醒中且本轮无 confirm 作用」的候选 +1；overflow 不计数；
   每 turn 每候选最多 +1
3. **降级触发**：暴露 ≥3 自动移入 archive `[ignored-3x]` 并清出暂存；提醒静默
4. **ignore 分支**：`action=ignore` + `reasonCode` → archive `[ignored]`，不入知识库
5. **曝光窗口**：>3 条时只展示 top 3（decision/troubleshooting 优先），溢出标积压；
   确认后补位
6. **解析兼容**：`[⏳N]` 剥离；旧格式（无标记）strikes=0
7. **配置**：`inlineConfirm:false` 回退旧行为；`confirmStrikes`/`remindCooldownTurns` 可调
8. **并发安全**：多回合并发提醒/确认下暂存区一致（serializedWrite）
9. **回归**：现有 109 测试全绿

## 5. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 提醒变吵 | 空态提醒①冷却（5 turn）+ 非平凡门槛（有工具调用）；`inlineConfirm:false` 总开关 |
| 暴露语义误伤 | 只对曝光窗口内候选计数；overflow 不计数；降级可逆（archive） |
| agent 滥用忽略 | `reasonCode` 枚举可统计；compact 报告可见 ignored 数量 |
| 多会话共享暂存区 | 全部写走 serializedWrite；计数为目录级全局值（接受，简化） |
| 降级误伤重要候选 | 仅移入 archive（可逆）；`confirmStrikes` 可调大 |
| 行内标记污染阅读 | 解析剥离 + 渲染转「第 M 次提醒」；标记格式固定单一 |

## 6. 明确不做

- 不做自动抽取入库；不做 UI 按钮；不做会话级候选归属；不做「任务结束弹窗」
